# Iris Estética Itu — versão HTML/Bootstrap

Projeto estático composto por HTML, CSS, Bootstrap 5 e JavaScript puro.

## Como visualizar

Abra `index.html` no navegador. Para publicação, envie toda a pasta para a hospedagem mantendo a estrutura de diretórios.

## Estrutura

- `index.html`: conteúdo e estrutura do site
- `css/style.css`: identidade visual e responsividade
- `js/script.js`: links, menu e comportamento da navegação
- `assets/`: logo e imagem de compartilhamento

O Bootstrap e as fontes são carregados por CDN, portanto a página precisa de internet para exibir esses recursos.
